# Agents

## Project Overview

This project is an interactive multiplayer quiz application built with Node.js, Express and Socket.IO.

The application allows multiple players to join a quiz room, answer questions in real time and compete for points.

## Basic Instructions

1. Keep the existing project structure.

2. Do not remove or break existing quiz functionality.

3. Keep the server-side game logic in `server.js`.

4. Keep the quiz questions and answers in `quizData.json`.

5. Keep the data-reading logic in `readData.js`.

6. Keep the website files inside the `public` folder.

7. Use Socket.IO for real-time communication between the server and the players.

8. Keep the maximum number of questions per game at 7 unless this is intentionally changed.

9. Keep the existing scoring system unless a change is specifically required.

10. Test changes before committing them to the repository.

11. Keep the code readable and use clear variable and function names.

12. Do not remove existing features when adding new features.

13. Update `features.md` when a major new feature is added.

14. Update `README.md` if the project setup or usage instructions change.

15. Do not commit passwords, API keys, tokens or other private information.

16. When changing the Socket.IO events, make sure the corresponding client-side and server-side code are updated.

17. Keep the project compatible with the existing `package.json` dependencies.
